# Experiment 1: Git Operations Using GitHub and Visual Studio Code

**Student:** Kiran Patel  
**Experiment:** 1  
**Title:** Perform Git Operations Using GitHub and Visual Studio Code

## Aim
To learn and demonstrate Git version-control operations using GitHub and Visual Studio Code.

## Software required
- Git
- GitHub account
- Visual Studio Code
- Windows Command Prompt / PowerShell / VS Code terminal

## Repository
https://github.com/kiranpatelkiran8197-rgb/Experiment-1-Git-Operations

## Experiments covered
1. Create and clone a GitHub repository.
2. Create, modify, and delete files.
3. Check changes using `git status`.
4. Stage and commit changes using `git add` and `git commit`.
5. Push and pull changes between local and remote repositories.
6. Initialize a separate local repository.
7. Create and inspect branches; fetch and compare branch changes.
8. Merge a feature branch into `main`.
9. Create and merge a pull request.
10. Verify that the local and remote repositories are synchronized.

## Important note about evidence
The GitHub commit history and merged pull request in this repository are genuine remote GitHub records. Commands in `evidence/LOCAL_TERMINAL_STEPS.md` are provided for running and capturing the local VS Code terminal portion on the student's computer. Do not treat the command examples as screenshots or as proof that they were run locally.
