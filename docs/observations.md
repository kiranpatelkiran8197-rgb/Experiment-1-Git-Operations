# Observations

| Operation | Expected observation |
|---|---|
| `git init` | Initializes an empty local Git repository |
| `git status` | Shows untracked, modified, staged, or clean working-tree state |
| `git add` | Stages selected file changes |
| `git commit` | Records staged changes in local history |
| `git push` | Sends local commits to the remote repository |
| `git pull` | Fetches and integrates remote changes |
| `git branch -a` | Lists local and remote-tracking branches |
| `git fetch origin` | Updates remote-tracking references |
| `git diff main..branch` | Shows differences between the two branch tips |
| `git merge` | Integrates another branch into the current branch |
